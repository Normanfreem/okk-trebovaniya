# Блок «Письма ОКК» — готовый модуль для встраивания

Готовый реестр служебных писем (ВСЖМ-1, 4 этап) с поиском по полному тексту и статусами отмены.
Код писать не нужно — модуль подключается как есть. Читать `letters.json` целиком не нужно (это данные, ~1 МБ).

## Состав
| Файл | Что это |
|---|---|
| `okk-letters.js` | Модуль: реестр, поиск, фильтры, статусы, открытие PDF. Чистый JS, без зависимостей, стили внутри. |
| `letters.json` | Данные: 119 писем (реквизиты, суть, статусы, полный распознанный текст). |
| `pdf/` | 186 PDF: сами письма и приложения. Имена = поля `file` / `att[].file` в `letters.json`. |
| `demo.html` | Рабочий пример подключения (открыть через любой http-сервер). |

## Где взять данные (letters.json и pdf/)
- **Вариант А — архив** `okk-letters-module.zip` от владельца: данные уже внутри.
- **Вариант Б — репозиторий `okk-trebovaniya`** (папка `letters-module/`): код здесь, а данные лежат в зашифрованном `data.okk`. Достать:
  ```
  pip install cryptography openpyxl
  python3 letters-module/export_letters.py --pwd <пароль владельца> --out <папка вашей программы>/letters
  ```
  Получите `letters.json` и `pdf/`. Пароль спросить у владельца. Пароль, `letters.json` и PDF в публичный репозиторий НЕ коммитить.

## Подключение в веб-приложение (2 строки)
```html
<div id="letters"></div>
<script src="okk-letters.js"></script>
<script>OKKLetters.mount(document.getElementById('letters'), {data: 'letters.json', pdfBase: 'pdf/'});</script>
```
Опции `mount(el, opts)`:
- `data` — URL `letters.json` или уже загруженный объект;
- `pdfBase` — путь к папке с PDF (по умолчанию `pdf/`);
- `openPdf(url, fileName, letter)` — своя функция открытия PDF (по умолчанию новая вкладка);
- `title` — заголовок блока (`''` — без заголовка).
Возвращает `{search(text), letters()}`. React/Vue: вызвать `mount` в `useEffect`/`onMounted` на div-контейнер.
Цвета: CSS-переменные `--okl-accent`, `--okl-bg`, `--okl-card`, `--okl-ink` и др. на контейнере (список — в начале `okk-letters.js`).
Файлы должны отдаваться по http(s) (не `file://`), иначе `fetch` не загрузит `letters.json`.

## Не веб (бот, бэкенд, другая программа)
Используйте `letters.json` напрямую. Формат: `{asof, object, letters: [...]}`, у письма:
`num` номер · `date` ДД.ММ.ГГГГ · `from`, `to`, `reply` (ответ на) · `subj` тема · `sum` суть (2–4 предложения) · `kw` ключевые слова · `cat` категория · `kons[]` конструктивы ·
`status`: `active` | `changed` (изменено частично) | `cancelled` (отменено) · `cancelledBy` каким письмом отменено («№ … от …») · `cancels` какие отменяет · `changedBy` / `changes` частичные изменения с пояснением ·
`note` примечание · `file` PDF письма · `att[]` {file, what} приложения · `text` полный текст письма · `attText[]` тексты приложений.

## Правила (обязательно соблюдать при выводе)
- `status: cancelled` — письмо НЕ действует; показывать «Отменено. Взамен — …» (поле `cancelledBy`), опираться на письмо-замену.
- `status: changed` — часть требований заменена письмом из `changedBy`; читать вместе с ним.
- Тексты сканов распознаны автоматически — возможны опечатки в отдельных буквах; при сомнении — открыть PDF.
- Данные служебные: не публиковать в открытом доступе (публичный репозиторий, открытый сайт без входа).

## Обновление данных
Заменить `letters.json` и добавить новые PDF в `pdf/` (вариант Б: `git pull` в `okk-trebovaniya` и снова запустить `export_letters.py`). Код модуля не меняется.
